LedgerMathA book of record for cloud servers

Four times a day, LedgerMath boots 5 AWS machine types in us-east-2, runs 14 benchmarks on each and keeps every Run with its evidence. Each figure is a median, printed to every digit its published Method recorded, and the whole book is static JSON, so that AI agents can make infrastructure decisions from measured numbers.

For agents and developers

The ledger is static JSON at api.ledgermath.com. An agent reads one index, then every Series with its percentiles and the Method that made them, the day's On-Demand prices, and a JSON schema for each kind of file. Each Series' own file gives every Run's figure and a link to its evidence, so any number can be traced to what the machine printed.

Version 1 only ever gains fields: a field, once published, keeps its name, its type and its meaning.

  1. The indexWhat the API holds and where: the Series, the prices, the schemas and the evidence.
    $ curl https://api.ledgermath.com/v1/index.json
  2. Every SeriesAll 187, each with its percentiles, its Runs counted and its own file's address.
    $ curl https://api.ledgermath.com/v1/series.json
  3. The prices, 2026-11-19AWS's public On-Demand prices for the five machine types, copied daily.
    $ curl https://api.ledgermath.com/v1/prices/2026-11-19.json
  4. One Series' own fileEvery Run's figure and a link to its evidence, at api.ledgermath.com/v1/series/<id>.json. This one holds the Run quoted here.
    $ curl https://api.ledgermath.com/v1/series/c2d748916b19.json

How a figure is kept

  1. RunA fresh machine boots at 04:10, 10:10, 16:10, 22:10 UTC and runs the benchmarks on it; each Run starts some time after the boot. What the benchmark printed and what was recorded about the machine are kept as evidence, addressed by SHA-256.
  2. SeriesThe Runs that share a benchmark, params, build, instance type and zone ID.
  3. MethodA versioned Method turns a Series' Runs into its figures. Method series v1 takes each Run's median time per repetition, then the 5th, 50th and 95th percentiles across the counted Runs.
  4. FigureThe median, as written in the ledger above: nothing rounded, nothing computed that the Derivation does not hold.
