Prompt for your agent

LedgerMath measures 5 AWS EC2 machine types in us-east-2, 14 benchmarks each, four times a day, and publishes the figures with AWS's On-Demand prices as static JSON. Start at https://api.ledgermath.com/v1/index.json. https://api.ledgermath.com/v1/series.json lists every Series with its p5, p50 and p95. Prices: https://api.ledgermath.com/v1/prices/2026-11-19.json. Cite each figure's Series file (https://api.ledgermath.com/v1/series/<id>.json), which lists every Run behind it with a link to its evidence. Do not state a figure the API does not give.

  • # every Series, with p5, p50, p95

    curl https://api.ledgermath.com/v1/series.json

  • # 01 c8i.2xlarge: each Run, its evidence

    curl https://api.ledgermath.com/v1/series/50454c4ad4d9.json

  • # prices, 2026-11-19

    curl https://api.ledgermath.com/v1/prices/2026-11-19.json
