DESCRIPTION

LedgerMath boots AWS machines four times a day, at 04:10, 10:10, 16:10 and 22:10 UTC, and runs 14 benchmarks on each freshly booted machine. Every execution is kept as a Run, with its evidence: what the benchmark printed, and what was recorded about the machine. A Series is the Runs of one benchmark, setting, build, machine type and zone; a published Method derives its figures.

5 machine types in us-east-2 are measured. The figures, the evidence and AWS's public On-Demand prices, copied daily, are served as static JSON at api.ledgermath.com.

METHODS

A versioned Method turns a Series' Runs into a Derivation, and its words are published with the data, in /v1/series.json. The DATA above is Method series v1:

time_per_repetition
Per Run: for each counted sample (warmup samples left out), sample_ended.t minus sample_started.t, divided by the sample's repetitions; the Run's number is the median of those (the mean of the two middle values when there is an even number of samples).
bytes_per_second
Per Run, where the benchmark observed bytes_per_repetition: bytes_per_repetition × 10^9 / the Run's time per repetition in nanoseconds.
percentiles
5th, 50th and 95th percentiles across the counted Runs of a Series, and of each group, by linear interpolation between closest ranks (R type 7): with n values sorted, h = (n − 1) × p / 100 and the percentile is x[⌊h⌋] + (h − ⌊h⌋) × (x[⌊h⌋+1] − x[⌊h⌋]). Each number's percentiles are taken over that number's values, so the bytes-per-second percentiles are not the time percentiles inverted.
counted
A Run counts when its binary exited 0, every stdout line is an event that matches the events schema, and the stream obeys every order rule scripts/check-events.py checks: started first and once (not a --quick stream), finished last and once, samples numbered from 0, each closed by its own sample_ended before the next starts and never ending before it starts, observed keys once, exactly one verified, and as many counted samples as the Run asked for. Any other Run is failed: shown, with the reasons, and in no percentile.

Also published: Method requests v1, for the request phases of http_get.
