# No condition or procedure values in the Ledger

No Variant value and no Run field records a condition such as cold, warm, fresh, or first fetch, even though a Benchmark may be built to provoke such paths. We cannot verify a provider's internal state, a provider can game a procedure, and any such label leads readers to a conclusion we cannot back. Facts a provider hands our own code are kept as event attributes, and the numbers speak for themselves.
