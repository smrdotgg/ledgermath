# Withdrawal keeps the hash

Bytes leave the Archive's public copies only by a reviewed index commit that marks the entry Withdrawn with a reason and a date; the hash, the build records, and every Run that cites them stay, and the compliance copy keeps the bytes for its retention period. Deletion was rejected because the first legal demand or leaked secret would otherwise force a choice between breaking Runs and lying in the index, which is what crates.io's untraced deletions produced. Modelled on Software Heritage's masking.
