# The stdout contract is a stream of events, one JSON object per line

_Changed by ADR-0029: a benchmark's own events are documented in its `README.md`, not declared in `benchmark.ts`, and the runner writes the benchmark's name and params into the Run instead of their being joined from a manifest._

A binary prints newline-delimited JSON to stdout: one complete object per line, each an event with a whole-nanosecond `CLOCK_MONOTONIC_RAW` timestamp. Six universal events (`started`, `observed`, `sample_started`, `sample_ended`, `verified`, `finished`) are emitted by the harness, and a Benchmark may add events of its own, declared in its `benchmark.ts`. The stream carries no aggregate, no declared value, and no Benchmark or Variant name: aggregates are Derivations, declared values are joined from the manifest by Station, and the names are known to whoever launched the binary. The checksum travels as a hex string because a 64-bit value does not fit a JSON number. The JSON array of result records from the July 2026 proof of concept was rejected because an array must be closed before any parser accepts it, so a crash in the third sample left no readable evidence, and because every field in those records other than the raw samples was either derivable or declared. The cost is that every binary in every language emits this exact shape, and that a sample's timing is two timestamps and a repetition count rather than a number, so no reader gets a nanoseconds-per-operation figure without a Method.
