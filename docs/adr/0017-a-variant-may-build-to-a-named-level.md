# A Variant may build to a named level

A Variant's requirement on the role that runs the binary says how the Artifact is built for it: `native`, the default, which keeps ADR-0007's build from the compiler's own resolution on the bound Target's CPU profile, or a level or model the compiler names (`x86-64-v3`, `skylake-avx512`), for which one Artifact is built per level in use and the ingest Verdict checks that each Run's Capture supports the level rather than matches a profile. Per-silicon numbers alone were rejected for Targets whose silicon cannot be asked for, such as Lambda on x86_64 or an instance type that draws between two processor generations, because nobody deploys a binary there that runs only on some of the hardware they may be handed, so the per-silicon number is not the one anyone wants. A separate kind of Station was rejected because the per-role requirement slot already exists. The cost is that a Series under a named level mixes silicon by declaration, which readers see in the Variant and Methods may segment by the Capture hash every Run records. Amends ADR-0007, whose rejection of levels now applies to the default only.
