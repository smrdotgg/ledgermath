# Requirements over Target facts are JSON Schema, never functions

A Variant's `requires` block is a JSON Schema 2020-12 document in a small profile (`properties` whose entries carry `type` and `minimum`, `maximum`, `const`, or `enum`), written directly or as a Zod schema converted with `z.toJSONSchema`, evaluated against the Target's facts by one JSON Schema validator in CI and at ingest, and hashed in RFC 8785 canonical form inside the setup hash. Functions were rejected because the setup hash needs a stable spelling, the website must render a requirement without running it, Annotation scopes must match on it, and Go or Rust authors must read the same contract. A vocabulary of our own was rejected in favour of the standard, and an authoring library is only ever a way to produce the JSON Schema, never the validator.
