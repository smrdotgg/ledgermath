## How the user works

Read this before step 2. Each line changes how to answer them.

- They write by voice-to-text. Messages ramble, self-correct mid-paragraph, and sometimes withdraw a question before the end. Read to the end, then answer what survived.
- A compressed phrase where the argument should be reads to them as evasion. State the mechanism and one worked example, every time. There is no word budget.
- They want zero judgement left in the running system. A rule that needs taste is a defect; offer the mechanical replacement. A residual choice passes only when a wrong call costs money or effort, never truth.
- Regression detection is a second layer to them. The data must stay honest with detection switched off.
- They remember vocabulary through scenarios. Introduce a term inside a story, then define it.
- They retired the word "configuration". Say Variant, Station, or manifest, whichever is meant.
